# ADSP Phase 2 Closeout — 2026-08-20

## Decision

ADSP Phase 2 is **closed as an evidence phase, with Redis horizontal promotion rejected**.

The ActivityPods Redis-transporter topology now has complete correctness, scale, resource and node-loss evidence under the frozen benchmark contract. The failure/recovery gap that remained after canonical W1/W3 is closed by ActivityPods PR #106.

Closing the evidence phase does **not** mean the Redis horizontal profile earned promotion. The canonical W1 result remains frozen:

- N=10 scaled strongly;
- N=100 failed the 1→2 scale gate;
- N=100 failed the 2→4 scale gate, with 2→4 essentially flat.

Because the frozen contract requires both scale transitions to meet the promotion rule, Redis P2 is **non-promotable**. The later node-loss success cannot be used to reinterpret or relax those scale results.

Consequently:

- ADSP Phase 3 NATS Core comparison **does not open**;
- NATS Core remains an unselected candidate, not an authorized next benchmark;
- JetStream remains blocked behind its separate reproduced-limitation entry gate;
- the incumbent Redis responsibilities and Fedify-sidecar Redis Streams durability remain unchanged.

## Node-loss result

The lane exercised four real distributed ActivityPods/SemApps Pod cells on the incumbent Redis Moleculer transporter with real `activitypub.outbox.post` roots.

A deterministic ambiguous-commit boundary on replica 4 completed the authoritative root action, recorded `root-action-complete-response-held`, withheld the caller response, then allowed SIGKILL.

Observed final evidence:

- selected victim root entry: exactly one;
- held-response boundary timestamp: before the pre-SIGKILL fault epoch and before the SIGKILL completion marker;
- fault burst: 7 caller-accepted, 1 selected caller-rejected;
- selected rejected request was never retried by the harness;
- survivor accepted work covered r1/r2/r3;
- post-rejoin accepted work covered r1/r2/r3/r4;
- 23 accepted request IDs were unique;
- 23 accepted Activity IDs were unique;
- no duplicate measured completed traces were observed.

### Conservative recovery clock

A Codex review correctly identified that the first recovery clock could undercount time spent issuing SIGKILL. The final lane therefore uses a second independent broker that proves the four-endpoint baseline before fault injection and enforces an absolute deadline from an epoch written immediately **before** SIGKILL.

Final authoritative 4→3 convergence:

- `16,225 ms` from pre-SIGKILL `fault-start` to three observed endpoints;
- frozen bound: `30,000 ms`;
- result: PASS.

Application completion latency remains diagnostic and is not substituted for fabric/semantic recovery timing.

## Program consequence

Phase 2 has now answered its architectural question:

> Can the incumbent Redis Moleculer transporter form a correct horizontal ActivityPods baseline, and does that baseline satisfy the frozen promotion contract?

Answer:

- **Correctness/failure behavior: yes.**
- **Promotion-scale behavior: no.**

This is a legitimate completed phase with a negative promotion decision, not an unfinished phase and not permission to lower the gates.

The ordered ADSP Phase-3 NATS experiment therefore remains blocked. Phase-4/5 durable-subsystem experiments also remain conditional and do not open by implication.

The next active implementation work is the separately queued **ActivityPub Interoperability Hardening** phase, which does not change the ADSP transporter decision and must preserve the same ActivityPods/SemApps authority and privacy boundaries.
